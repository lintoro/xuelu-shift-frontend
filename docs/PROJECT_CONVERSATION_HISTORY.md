### 對話輪次 3：Vercel 部署連線問題排查與 .env.local 環境變數解析

* **時間**：2026-09-19 01:58 ~ 02:05
* **主管反饋與指示**：
  > `vercel有推了嘛 現在網頁版都連不上資料庫 還有什麼沒有部署完成的關係嘛 還是.env.local裡設定的問題`  
  > `我發現我有一個.env.local 及.env 裡面都有貼上 VITE_GAS_API_URL 但.env.local有vite_API_SECRET 所以是不再需要.env了嘛`
* **AI 分析與處置**：
  - **連不上原因**：地端 `.env.local` 含有敏感密鑰，被 `.gitignore` 排除不推送到 GitHub。Vercel 構建時若未在後台設定環境變數，前端會優雅降級為「本地沙盒模式」。
  - **.env vs .env.local**：Vite 讀取時 `.env.local` 優先度高於 `.env`。為防範真實網址與金鑰外洩，建議保留 `.env.local` 並將 `.env` 刪除，只需在 Vercel 後台 Settings ➔ Environment Variables 設定這兩組變數即可。

### 對話輪次 4：Vercel CI/CD 建置錯誤 MODULE_NOT_FOUND 排查與修復

* **時間**：2026-09-19 02:14 ~ 02:16
* **主管反饋與指示**：
  - 主管附截圖，Vercel 部署日誌噴出：
    `code: 'MODULE_NOT_FOUND', Error: Command "npm run build" exited with 1`。
* **AI 分析與處置**：
  - **根本原因排查**：`package.json` 中的 `build` 指令原為 `"npm test && vite build"`。在 Vercel 雲端環境執行時，`npm test` 試圖讀取 `scratch/` 內的測試腳本，而 `scratch/` 被 `.gitignore` 排除，導致 Vercel 找不到測試檔案而報錯中斷！
  - **修復方案**：將 `package.json` 的 `build` 指令更正為標準 `"vite build"`。
  - 地端建置成功後執行 `git commit`（`4c352a5`）並 `git push origin main`。
